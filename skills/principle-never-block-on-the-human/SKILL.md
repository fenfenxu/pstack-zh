# 不因人类而阻塞

人类异步监督。Agent 必须保持畅通。做合理决策并继续，让人事后纠偏。代码变更可逆且可审查，错误决策通常比阻塞成本更低。

- 先做，再展示。完成工作并展示结果。不要问「我该做 X 吗？」去做 X，并解释原因。
- 让系统能自愈。发现问题就记录下来，在下一轮修复。
- 不可逆动作（force-push、删除生产数据、发送外部消息）仍需确认。
- 可逆动作（写代码、编辑笔记、拆分任务）应直接推进，不要阻塞。
- 产品方向来自人类。执行不应阻塞。
