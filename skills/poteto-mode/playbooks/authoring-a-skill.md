### 编写或修改 skill

**你拥有 skill 的 voice。**

1. 使用 **create-skill** skill（Cursor 内置，用于编写 SKILL.md）。
2. 验证 skill：frontmatter 含 `name` 与 `description`，引用文件存在，跨 skill 链接可解析。
3. 若结构性强则写测试用例。若主观则 skip。
4. 运行 **Opening a PR**。

不确定时删除。只保留会改变决策的 prose。告诉它做什么，省略理由。仅当规则无解释会混淆时才解释。语气匹配 scope。按 **encode-lessons-in-structure** principle skill 指向结构来源（types、README、config）。按路径 delegate 到其他 skill。不要 restate。反复遇到但未 capture 的工作流 → 提议新 skill。

**Reply：** skill 摘要、关键设计决策、验证说明。
